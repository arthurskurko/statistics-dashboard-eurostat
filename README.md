# Estonia Statistics Dashboard

A Docker-ready React + TypeScript dashboard that lets you choose a Eurostat topic from a dropdown and add it to a chart dashboard.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- Apache ECharts
- Docker + Nginx

## Topics included

- Population (the card now uses two y‑axes when Estonia is plotted against the EU so the smaller line isn’t squashed)
- Immigration (total flows into Estonia and EU)
- Induced abortions (legal terminations, Estonia vs EU)


## Forecasting missing values

Some topics (e.g. abortion counts) may lack the latest EU aggregate because
not all countries have reported yet. The app can automatically generate a
short‑term forecast for any trailing gap by reading precomputed forecast
JSON files from `public/forecasts/`. Those JSON files are generated by a
Python script (the “Python/R method”).

To update the forecast data you need a Python 3 installation.
The required packages are listed in `scripts/requirements.txt`.

Install dependencies with:

```sh
pip install -r scripts/requirements.txt
```

Then generate (or regenerate) the forecast JSON files with:

```sh
npm run generate-forecasts
```

By default the script processes a small built‑in list of datasets
(abortions, migration, inflation); you can also specify additional
Eurostat dataset codes on the command line:

```sh
npm run generate-forecasts -- DEMO_FABORTORD prc_hicp_manr my_other_code
```

The output files appear under `public/forecasts/<code>.json`. The
frontend automatically loads any forecast file matching the active topic
and plots its values as a dashed, predicted series. You can adjust the
duration of the predicted horizon using the “Forecast” dropdown in each
card’s header.

Forecast points are drawn with a **dashed line** and are marked `predicted`
in the tooltip.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.

## Production build

```bash
npm install
npm run build
npm run preview
```

## Run with Docker

```bash
docker compose up --build
```

Then open `http://localhost:8080`.

## Notes

- The app fetches live data from Eurostat's public API.
- If a Eurostat dataset changes its filter codes, that chart can fail until the mapping is updated. For example the unemployment series dropped the 15‑74 age class in favour of 25‑74 in 2025, which required updating the app filters.
- Dashboard cards are persisted in local storage.
